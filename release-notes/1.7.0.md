# Achmage Bases Look 1.7.0 — 표에서 바로 썸네일, 머리글 한 줄 통째로

표 보기에서 썸네일을 넣으려고 칸반으로 갔다 오지 않아도 됩니다. 머리글은 한 칸씩도, 한 줄 통째로도 꾸미고, 노트에 넣은 베이스는 글 폭 안에 깔끔하게 들어갑니다.

- **표·목록에서 바로 썸네일 넣고 바꾸기.** 표의 썸네일 칸은 비어 있든 이미지가 있든 아무 데나 누르면 썸네일 창이 열립니다. 목록은 썸네일을 누르면 됩니다. 카드·칸반에만 있던 바꾸기 버튼 역할을 표와 목록에서는 썸네일 자체가 합니다.
	- 표의 빈 점선 칸을 눌러도 창이 안 뜨던 문제를 고쳤습니다. 점선 틀은 키보드로도 고를 수 있는 버튼이라, 마우스로 누르는 순간 틀에 포커스가 들어갔습니다. Obsidian은 포커스가 들어간 칸을 편집 중인 칸으로 보고 높이를 내용 크기(약 28px)로 줄이는데, 그 바람에 틀이 손 아래에서 쪼그라들어 손을 뗀 자리가 틀 밖이 되었고 클릭이 사라졌습니다.
	- 이제 마우스로 눌러도 포커스가 칸 안으로 들어가지 않고, 키보드 Tab으로 들어가도 칸이 행 높이를 유지합니다. 누른 순간 어느 노트였는지도 기억해 두어, 클릭이 빗나가도 창이 열립니다.
	- 썸네일 칸 위에서는 손가락 모양 마우스와 "썸네일 바꾸기" 안내가 뜨고, 이미지에 마우스를 올리면 테두리가 생깁니다.
	- Shift·Ctrl·Alt+클릭은 Obsidian 원래 동작(칸 범위 선택, 노트 열기)입니다. 카드·칸반의 점선 틀과 바꾸기 버튼에서도 보조키를 누른 클릭은 이제 창을 열지 않고 Obsidian에 넘깁니다. 유튜브 ▶·링크 버튼은 그대로입니다.
- **머리글 한 줄 통째로 서식.** 머리글을 우클릭해 **머리글 서식…**을 열면 범위에 **모든 머리글**이 생겼습니다. 고르면 머리글 한 줄 전체의 글자색·배경색(라이트·다크 따로)·굵게·기울임·정렬이 한 번에 바뀝니다.
	- 한 칸씩 정하는 머리글 서식은 그대로이고, 모든 머리글 서식 위에 얹힙니다. 한 줄을 정해 두고 몇 칸만 다르게 할 수 있습니다.
	- 엑셀에서 행 전체를 바꿀 때처럼, 모든 머리글에 정한 항목만 각 머리글의 같은 항목을 대신합니다. 예를 들어 배경색을 한꺼번에 바꿔도 각 머리글에 따로 정한 글자색·굵게는 남습니다.
	- 머리글 우클릭 메뉴의 **모든 머리글 서식 지우기**로 한 줄 전체(각 머리글의 서식 포함)를 Obsidian 원래 모습으로 되돌립니다. 조절 패널의 서식 개수에도 "모든 머리글"이 표시됩니다.
	- 저장 위치는 그 뷰의 `achmageLook.format.headerRow`입니다. 이 버전보다 예전 플러그인은 이 값을 모르고 넘어갑니다.
- **노트 속 베이스는 글 폭 그대로.** 노트에 넣은 표·칸반(`![[베이스.base]]`)이 이제 위아래 문단과 같은 글 폭 안에 머뭅니다. "읽기 쉬운 줄 길이"를 켜 둔 노트에서도 세로 종이 한가운데 가로 표를 억지로 끼운 것처럼 튀어나오지 않습니다.
	- 글 폭보다 넓은 표는 1.6.0처럼 왼쪽·오른쪽 끝(흐려진 부분)에 마우스를 두면 그쪽으로 넘어가고, 휠 버튼을 누른 채 끌어도 움직입니다. 표 아래 원래 스크롤 막대도 그대로입니다.
	- **노트에 넣으면 넓게 보기**는 이제 기본으로 꺼져 있습니다. 노트 폭까지 넓히고 싶은 뷰만 조절 패널 **이 뷰**에서 켜면 그 뷰에 `wideEmbed: true`가 쓰이고, 다시 끄면 지워집니다. 1.5·1.6에서 끄면서 남은 `wideEmbed: false`는 이제 기본값과 같은 뜻이라 그대로 두어도 됩니다.

**검증:**
- 자동 검사 82개를 통과했습니다(신규 1개: 모든 머리글 서식의 덮어쓰기·각 머리글 예외·본문에 안 번짐·지우기·파일 왕복. 머리글 한 줄 값 읽기와 서식 개수, 뷰 토글 기본값·저장·삭제는 기존 검사에 더함). TypeScript, Obsidian 심사 규칙 전체(`recommended`) 0건, 빌드, 버전 일치, 비밀정보 검사도 통과했습니다.
- Windows / Obsidian 1.15.1 테스트 볼트(별도 프로필)에서 다음을 확인했습니다.
	- 먼저 1.6.0에서 재현했습니다. 표의 빈 점선 틀을 누르면 누름은 틀에, 떼기와 클릭은 그 칸(`bases-td`)에 떨어져 창이 뜨지 않았습니다. 누른 칸은 안쪽 높이가 120px에서 28px로, 틀은 106px에서 14px로 줄어 있었습니다(Obsidian의 `.bases-td:focus-within { height: fit-content }`).
	- 1.7.0: 빈 틀 클릭, 빈 칸 귀퉁이 클릭, 이미지가 있는 칸의 이미지 클릭 모두 썸네일 창이 열립니다. 키보드로 틀에 포커스를 주고 Enter를 눌러도 열리고, 포커스가 들어간 칸은 120px·틀은 106px 그대로입니다. 클릭 뒤 틀에 포커스가 남지 않습니다. Shift+클릭은 창 없이 Obsidian 범위 선택, Ctrl+클릭은 창 없음, 글자 칸 클릭은 칸 선택입니다. 목록 뷰의 썸네일 이미지 7개가 모두 눌리고, 누르면 창이 열립니다.
	- 모든 머리글: 머리글 우클릭 메뉴에 "머리글 서식…", "머리글 서식 지우기", "모든 머리글 서식 지우기"가 뜨고, 서식 창 범위는 "머리글·모든 머리글·이 열의 칸"입니다. 모든 머리글에 초록 배경을 주면 썸네일 머리글까지 한 줄 전체가 초록이 되고, 굵게를 누르면 서식이 없던 머리글도 굵어지며 파일에는 `headerRow`로 저장됩니다. "모든 머리글 서식 지우기"로 원래 모습이 됩니다.
	- 노트 속 베이스(읽기 쉬운 줄 길이 켬, 읽기 모드): 기본으로 720px, 위 문단과 같은 폭·같은 왼쪽 위치입니다. 오른쪽 끝에 1.8초 두면 1,567px 옆으로 넘어갑니다. 조절 패널에서 넓게 보기를 켜면 945px로 넓어지고 그 뷰에 `wideEmbed: true`가 쓰이며, 끄면 720px로 돌아오고 파일이 켜기 전과 바이트까지 같아집니다.
	- 플러그인을 끄면 썸네일 칸 표시와 안내 문구가 모두 지워지고, 다시 켜면 돌아옵니다.
	- 확인 절차가 쓴 파일은 모두 원래 바이트로 돌아왔습니다(테스트 볼트 534개 대조, 시험 중 손으로 조작한 베이스 1개 제외).
- 맥(Cmd·Option), 모바일, 팝아웃 창, 다크 테마 화면은 실기로 확인하지 않았습니다.

In a table view you no longer have to switch to kanban to add a thumbnail. Headers can be formatted one by one or as a whole row, and a base embedded in a note fits neatly into the text.

- **Add or change a thumbnail right in a table or a list.** A click anywhere in the thumbnail cell of a table, empty or not, opens the thumbnail window; in a list, a click on the thumbnail does. In tables and lists the thumbnail itself does what the change button does on cards and kanban.
	- A click on the empty frame in a table did nothing. The frame is a button you can also reach with the keyboard, so a press put the focus on it. Obsidian treats a cell with the focus in it as a cell being edited and sizes it to its content (about 28 px): the frame shrank under the pointer, the release landed beside it and the click was lost.
	- A press no longer moves the focus into the cell, and a cell reached with Tab keeps the height of the row. The press also remembers which note it was for, so the window opens even when the click misses.
	- Over the thumbnail cell the pointer is a hand with a "Change thumbnail" tooltip, and the image gets an outline under the mouse.
	- Shift, Ctrl and Alt clicks keep Obsidian's behavior (select a range of cells, open the note), now also on the frames and change buttons of cards and kanban. The YouTube ▶ and link buttons work as before.
- **Format all headers at once.** Right-click a header and open **Format header…**: the scopes now include **All headers**, which formats the whole header row in one go, with text and fill colors (separately for the light and dark theme), bold, italic and alignment.
	- Formatting one header at a time stays, on top of the format for all headers: set the whole row once, then make a few headers different.
	- As when you format a whole row in a spreadsheet, a change for all headers replaces only what it changes in each header. A new fill for all headers keeps the text color and bold that a header has of its own.
	- **Clear formatting of all headers** in the header menu brings the whole row, each header's own format included, back to Obsidian's look. The format count in the look panel shows "all headers" too.
	- It is stored in that view's `achmageLook.format.headerRow`. Earlier versions of the plugin skip it.
- **Embedded bases keep the width of the text.** A table or kanban embedded in a note (`![[base.base]]`) now stays in the text column, as wide as the paragraphs around it. With readable line length on, it no longer sticks out like a landscape table squeezed into the middle of a portrait page.
	- A table wider than the text moves sideways when you rest the mouse at its left or right edge (the faded part), or when you drag it with the wheel button, as in 1.6.0. The table's own scrollbar stays.
	- **Wider when embedded in a note** is now off by default. Turn it on in **This view** of the look panel for a view that should spread out to the width of the note: it writes `wideEmbed: true` to that view, and turning it off removes it. A `wideEmbed: false` left from turning it off in 1.5 or 1.6 now means the same as the default and can stay.
