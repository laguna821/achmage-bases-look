# Achmage Bases Look 1.2.0 — 뷰마다 자기 모양, 설정은 베이스 파일 안에

같은 베이스 안에서도 칸반·카드·목록·표 뷰가 각자의 모양을 갖고, 플러그인 전체 설정은 연결만 남겼습니다.

- **뷰마다 따로 설정합니다.** 조절 패널의 **이 뷰**에서 그 뷰만의 크기·모양·표시를 정합니다. 한 뷰를 바꿔도 다른 뷰는 그대로입니다.
	- 크기: 카드는 카드 크기, 칸반은 열 너비, 표는 줄 높이, 목록은 썸네일 크기
	- 썸네일 모양(1:1~2:3)과 맞춤
	- 빈 썸네일 칸, 표·목록 정돈
	- 마우스 올림(카드 띄우기, 줄 강조와 색)
	- 그룹 모양(배경·강도·테두리·제목)
- **뷰 설정은 그 뷰 안에 저장됩니다** (`views[].achmageLook`). Obsidian이 자체 설정을 저장하거나 뷰 이름을 바꿔도 그대로 남습니다.
- **썸네일 버튼은 지금 보는 뷰에만 작용합니다.** 모든 뷰를 한 번에 켜고 끄려면 **이 베이스**의 버튼이나 명령 팔레트를 씁니다. "썸네일 (모든 뷰에 한 번에)" 크기·모양 설정은 없앴습니다.
- **플러그인 설정에는 연결만 남았습니다** (Cloudflare R2, Eagle). 다음은 모두 베이스 파일에서 정합니다.
	- 베이스마다: 썸네일 속성, 링크 속성, 이미지 폴더, 저장 위치(기본 위치·위치 묻기·R2 사본), 새 칸반 자동 묶기와 그룹 속성
	- 뷰마다: 모양
- **그룹 색은 베이스 공통입니다.** 같은 값은 어느 뷰에서나 같은 색입니다. 배경·테두리·제목 같은 그룹 모양은 뷰마다 정합니다.
- **명령 추가:** "이 베이스의 모양 패널 열기"
- **업데이트만으로는 아무 파일도 바꾸지 않습니다.** 예전 버전에서 베이스 전체에 정한 모양이나 플러그인 설정에서 정한 값은 각 뷰에서 바꿀 때까지 그대로 적용됩니다.

**검증:**
- 자동 검사 47개를 통과했습니다. TypeScript·Obsidian 심사 규칙 전체(`recommended`) 0건·빌드·버전 일치·비밀정보 검사도 통과했습니다.
- Windows / Obsidian 1.14.4 테스트 볼트(사본 베이스)에서 다음을 확인했습니다.
	- 카드 크기를 바꾸면 그 뷰만 바뀝니다.
	- 목록과 표(목록형)의 썸네일 크기·모양이 따로 적용됩니다.
	- 칸반의 그룹 배경과 카드의 띄우기가 서로 영향이 없습니다.
	- 도구 막대 썸네일 버튼은 그 뷰만 바꾸고, 모든 뷰 켜기는 전체에 적용됩니다.
	- 설정 탭에는 연결만 보입니다.
	- Obsidian 자체 저장과 뷰 이름 변경 뒤에도 뷰 설정이 유지됩니다.
	- 기존 `덕질 칸반.base`·`무제.base`·`무제 1.base`는 열어도 변화가 없습니다.
	- 플러그인을 끄면 순정 썸네일이 보입니다.

---

- **Each view keeps its own look.** **This view** in the look panel sets, for that view only:
	- its size (card size, column width, row height or list thumbnail size)
	- thumbnail shape and fit
	- dashed frames and tidying
	- hover
	- group look

	Changing one view never changes another.
- **View settings live inside the view** (`views[].achmageLook`) and survive Obsidian's own saves and view renames.
- **The Thumbnails button works on the view on screen.** Every view on or off is a separate button under **This base**, and a command. The "every view at once" size and shape section is gone.
- **The plugin settings hold connections only** (Cloudflare R2, Eagle). Everything else is set in the base file:
	- Per base: thumbnail property, link property, image folder, saving and new-kanban settings.
	- Per view: the look.
- Group colors stay shared by the views of a base.
- New command: "Open the look panel of this base".
- Updating rewrites nothing: values from earlier versions keep applying until a view sets its own.
