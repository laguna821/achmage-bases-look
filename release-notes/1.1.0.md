# Achmage Bases Look 1.1.0 — 베이스별 설정, 기존 설정 보호

이미 자기 방식으로 설정해 둔 베이스를 덮어쓰지 않고, 베이스 파일 하나하나 단위로 설정할 수 있게 했습니다.

- **기존 설정을 건드리지 않습니다.** 자기 속성(`cover`, `banner` 등)으로 이미지를 보여 주던 베이스는 그 속성을 찾아 그대로 씁니다. **썸네일**을 켜도 이미지가 없는 뷰만 채우고, 이미 있는 이미지 설정·비율·맞춤·카드 크기·직접 맞춘 열 너비는 바꾸지 않습니다. 파일·수식 이미지를 쓰는 뷰와 직접 만든 `image()` 수식도 그대로 둡니다. 껐다 켜도 그 베이스의 속성을 기억합니다.
- **베이스마다 따로 설정합니다.** 조절 버튼의 새 **이 베이스** 섹션에서 그 베이스만의 썸네일 속성·링크 속성·이미지 폴더·새 칸반 자동 묶기·목록 썸네일 크기를 정합니다. 입력하면 그 베이스 노트들이 쓰는 속성을 검색하고, 속성마다 노트 몇 개·이미지 몇 개(링크는 웹 주소 몇 개)인지 보여 줍니다. 고르거나 Enter를 눌러야 적용되며, 검색만 하다 나가면 아무것도 바뀌지 않습니다. 설정은 그 베이스 파일에만 저장되고 **이 베이스를 기본값으로**로 되돌립니다.
- **썸네일 창이 저장 위치를 알려 줍니다.** 카드에서 연 창은 그 베이스의 속성·폴더·링크 속성으로 저장하고, 어디에 저장되는지 창 위에 표시합니다.
- **열기만 해서는 바뀌지 않습니다.** 새 칸반 자동 묶기는 새로 만든 베이스나 방금 칸반으로 바꾼(추가한) 뷰에만 적용합니다. 이미 있는 그룹 없는 칸반은 파일을 바꾸지 않고 "바로 시작" 버튼만 보여 줍니다.
- **정돈 CSS 범위 축소.** 표·목록 이미지 정돈이 모든 베이스의 모든 이미지에 걸리던 것을, 이 플러그인이 설정한 베이스의 썸네일에만 적용합니다.
- **설정 화면 정리.** 플러그인 설정은 "베이스 기본값"이며, 베이스마다 바꿀 수 있다고 안내합니다.

**플러그인을 지워도** 썸네일은 보통 노트 속성이고 베이스는 순정 Bases 설정(`image`, `image()` 수식)만 쓰므로, 순정 Bases가 그대로 보여 줍니다(README에 정리).

**검증:**
- 자동 검사 44개를 통과했고, TypeScript·Obsidian 심사 규칙 전체(`recommended`) 0건, 빌드, 버전 일치, 비밀정보 검사도 통과했습니다.
- Windows / Obsidian 1.14.4 테스트 볼트에서 다음을 확인했습니다.
	- `cover`를 쓰는 베이스를 열어도 파일이 바뀌지 않음, 속성 감지, 이미지 있는 카드에는 점선 칸 없음
	- 그 베이스에서 넣으면 `cover`에 저장되고 `썸네일`은 그대로
	- 껐다 켜도 `cover`·비율 1.5·직접 정한 열 너비 유지
	- 직접 만든 수식 열은 정돈하지 않음
	- 기존 칸반은 그대로, 새 베이스는 자동 묶기
	- 베이스별 링크 속성·이미지 폴더
	- 속성 검색·고르기·Enter 적용, Esc나 다른 곳 클릭은 되돌림
	- 플러그인을 끈 상태의 순정 카드·칸반·목록 썸네일 표시
	- `덕질 칸반.base` 변화 없음

---

- **Your existing setup is kept.** A base that shows images from its own property (`cover`, `banner`, …) keeps using it. Turning thumbnails on only fills views without an image and never replaces an image setting, ratio, fit, card size or a column width you set. Views with file or formula images and your own `image()` formulas stay as they are. The base remembers its property when you turn thumbnails off and on.
- **Settings per base.** The new **This base** section of the look panel sets the thumbnail property, link property, image folder, kanban grouping and list size of that base only. Typing searches the properties its notes use, with how many notes and images each has. A value applies when you pick it or press Enter. Settings are stored in that base file; **Use the defaults for this base** clears them.
- **The thumbnail window says where it saves,** using the settings of the base it was opened from.
- **Opening a base changes nothing.** Automatic kanban grouping is limited to new bases and views that just became a kanban; an existing ungrouped kanban gets the start button only.
- **Narrower tidy look.** The table and list image tidying applies only to the thumbnails of bases this plugin set up, not to every image in every base.
- The plugin settings are now presented as defaults for bases.
