# Achmage Bases Look 1.0.3 — 새 칸반 바로 쓰기

새로 만든 칸반이 "속성 선택" 빈 화면에서 멈추지 않고, 바로 카드가 보이게 했습니다.

- **새 칸반은 바로 카드가 보입니다.** 그룹 기준이 없는 칸반 뷰(새 베이스를 칸반으로 바꾸거나 칸반 뷰를 추가한 경우)는 자동으로 그룹 속성을 정합니다. 노트에 상태 속성(상태, status, state, 단계 등)이 있으면 그 값별 열로, 없으면 설정의 기본 속성(기본 `상태`)으로 묶어 모든 카드가 **"없음" 열**에 먼저 모입니다. 그다음 **그룹 추가**로 열을 만들고 카드를 끌어다 놓으면 됩니다.
- **직접 지운 그룹 기준은 그대로 둡니다.** 그룹 메뉴에서 그룹 기준을 지우면 다시 묶지 않고, 빈 화면의 "속성 선택" 옆에 **"'상태'로 바로 시작"** 버튼을 보여 줍니다. 설정 **새 칸반 바로 쓰기**를 끄면 자동으로 묶지 않고 이 버튼만 보입니다.
- **"없음" 그룹 보정:** 값 없는 그룹("없음")에는 이름 바꾸기 연필이 뜨지 않습니다. 이름을 바꿔도 노트는 그대로이고 그룹 순서만 어긋날 수 있었기 때문입니다. 아직 카드가 없는 그룹은 계속 이름을 바꿀 수 있습니다.

**검증:** 자동 검사 34개, TypeScript·Obsidian 심사 규칙 전체(`recommended`) 0건·빌드·버전 일치·비밀정보 검사 통과. Windows / Obsidian 1.14.4 테스트 볼트에서 확인했습니다.
- 상태 값이 있는 폴더의 새 칸반은 값별 열로 묶였습니다.
- 상태가 없는 노트의 새 칸반은 "없음" 열로 묶였습니다.
- 그룹 추가, 카드 이동, 그룹 기준을 지웠을 때 다시 묶이지 않는 동작, 시작 버튼, 설정을 끈 경우를 확인했습니다.
- 기존 베이스는 바뀌지 않았습니다.

---

- **New kanban views show their cards at once.** A kanban view without a group property used to show only “Choose a property”. It is now grouped automatically: by a status property the notes already use (status, state, stage, 상태 …), or else by the property from the settings (`status` by default), so every card first shows under **None**. Add columns with **Add group** and drag cards into them.
- **A grouping you removed stays removed.** Instead, a **Start with “status”** button appears next to Obsidian's “Choose a property”. Turning off **Ready-to-use new kanban views** in the settings leaves only that button.
- **Fixed:** the group without a value (“None”) no longer offers a rename button, which could only break the group order. Groups without notes can still be renamed.
