First release of **Achmage Bases Look**: thumbnails and group colors for core Bases views.

- Thumbnails for cards, kanban, table and list views, turned on for a whole base with one click.
- Dashed frames on cards without an image: click, or drop an image file or web image.
- Thumbnail window: drop or paste an image, enter an address, upload to Cloudflare R2 (CMDS Eagle worker), or pick from Eagle.
- One size, shape and fit for every view of a base, from the sliders button in the Bases toolbar.
- Group colors with background tint, border and heading emphasis, set in the native Group menu.
- Hover lift for cards and row highlights for tables and lists.

Requires Obsidian 1.13 or newer; kanban needs 1.14.
