# Achmage Bases Look 1.0.4 — 유튜브 링크 지원

유튜브 링크를 넣으면 영상 미리보기가 썸네일이 되고, 썸네일의 ▶ 버튼으로 바로 영상을 엽니다.

- **유튜브 링크 = 썸네일.** 썸네일 창의 주소 칸에 유튜브 링크를 붙여넣거나 카드에 끌어다 놓으면 그 영상의 미리보기 이미지가 썸네일이 됩니다. `youtube.com/watch`, `youtu.be`, `shorts`, `embed`, `live` 주소와 마크다운 링크 안의 주소를 모두 알아봅니다. 큰 미리보기(1280×720)가 있으면 그것을, 없으면 기본 미리보기를 씁니다. 볼트 저장, Cloudflare R2 업로드, 링크만 모두 됩니다.
- **▶ 버튼으로 영상 열기.** 영상 주소는 노트의 **링크 속성**(기본 `링크`)에 저장됩니다(`t=` 시작 시간 유지). 링크가 있는 노트의 썸네일에는 카드·칸반에서 가운데 ▶ 버튼, 표·목록에서 작은 ▶ 표시가 뜨고, 누르면 브라우저에서 유튜브가 열립니다. 카드의 다른 곳을 누르면 지금처럼 노트가 열립니다.
- **다른 웹 링크도 열기.** 링크 속성에 유튜브가 아닌 웹 주소가 있으면 썸네일 모서리에 열기 버튼이 뜹니다.
- **기존 링크 보호.** 링크 속성에 이미 다른 주소가 있으면 덮어쓰지 않고 알려 줍니다. 비어 있거나 다른 유튜브 영상일 때만 바꿉니다. 설정에서 속성 이름을 바꾸거나 비워서 끌 수 있습니다.

**검증:** 자동 검사 35개, TypeScript·Obsidian 심사 규칙 전체(`recommended`) 0건·빌드·버전 일치·비밀정보 검사 통과. Windows / Obsidian 1.14.4 테스트 볼트에서 다음을 확인했습니다.
- 주소 칸 안내 문구
- 볼트 저장: 큰 미리보기 이미지와 `링크`·시작 시간 저장
- 칸반·카드·표·목록의 ▶ 버튼 위치
- ▶ 클릭 시 열리는 주소와, 노트가 열리지 않는 것
- 링크만 저장
- 기존 다른 링크 보존, 없는 영상의 오류 안내

---

- **YouTube links become thumbnails.** Paste a YouTube link into the address field, or drop it on a card, and the video's preview image becomes the thumbnail. Watch, youtu.be, shorts, embed and live addresses all work, also inside a Markdown link. The large preview (1280×720) is used when the video has one. Vault, Cloudflare R2 and link-only storage all work.
- **Open the video with ▶.** The video address is saved in the note's **link property** (`link` by default), keeping a `t=` start time. Thumbnails of notes with a link get a ▶ button (cards and kanban) or a small ▶ badge (tables and lists) that opens the video in your browser. The rest of the card still opens the note.
- **Other web links too.** A non-YouTube web address in the link property gets an open button in the thumbnail's corner.
- **Your links are safe.** A different address already in the link property is never overwritten; only an empty value or another YouTube video is replaced. Rename the property, or leave it empty to turn this off, in the settings.
